Pierwsza wersja Polskiego Studia Map – atlasu 3D Polski, z którego powstanie multimapa z dziesiątkami warstw.

- Zasięg ograniczony do Polski: kamera, teren, ortofoto GUGiK, nazwy, szlaki i wyszukiwarka.
- Bez wyszukiwania tras, profilu i przelotu – na razie usunięte z programu.
- Zostają: style mapy, Słońce i cienie, soczewki, pole widoczności, pomiar, linia wzroku i panorama.
- Program sam proponuje kolejne wersje z redzikowski.com.
